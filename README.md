## 🚀 Quick Start

### Prerequisites

- **Node.js** `16+` and **npm**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/malikmahmad/CareerMint.git

# 2. Move into the directory
cd CareerMint

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

> The app will open at **http://localhost:5173**

### Build for Production

```bash
npm run build
```

> Output is generated in the `dist/` folder, ready for deployment on Vercel, Netlify, or any static host.

## 📋 Resume Sections

CareerMint supports all standard resume sections — each fully customizable:

- 👤 **Personal Info** — Name, email, phone, location, social profiles
- 📝 **Professional Summary** — Brief background overview
- 🎓 **Education** — Degrees, institutions, GPA, graduation dates
- 💼 **Experience** — Job titles, companies, dates, responsibilities
- 🛠 **Projects** — Portfolio work with descriptions and links
- ⚙️ **Skills** — Frontend, backend, database, tools & more
- 🏅 **Additional** — Certifications, languages, awards, interests
